RUN IN KAGGLE
Attach the existing dataset, rather than creating another copy:
https://www.kaggle.com/datasets/odedkovach/padel-racket-specifications-with-sources
Import the source notebook and Run All. CPU is sufficient. No internet access, secrets, or additional packages are needed in Kaggle's Python notebook environment. The loader finds rackets.json under /kaggle/input. If multiple distinct PadelTrue snapshots are attached, set PADEL_DATA_PATH explicitly to one file.

RUN LOCALLY
Use Python 3.11 or later with Jupyter/IPython. Supply a frozen copy of the public rackets.json beside the notebook, or point PADEL_DATA_PATH at that file before starting Jupyter. Within a clone of the public data repository, set PADEL_DATA_PATH to the repository's rackets.json; when starting Jupyter from this examples/provenance-audit folder, ../../rackets.json is the corresponding relative path.

Public source and definitions:
https://padeltrue.com/data

INTERPRETATION
A syntactically valid source link does not prove the claim, page availability, or exact-model match. Manufacturer/retailer are recorded labels. Missing from this collection does not mean absent from the market. Input completeness is not equipment quality. Export dates never replace missing observation dates. No price availability, stock, performance, injury, sales, or user behavior is inferred.
